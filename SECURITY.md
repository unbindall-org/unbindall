# Security Policy

Bitte veröffentliche Sicherheitsprobleme nicht zuerst als öffentliches Issue. Nutze nach Veröffentlichung des Repositorys GitHub Private Vulnerability Reporting oder kontaktiere den Maintainer über die dort hinterlegte Sicherheitsadresse.

Gib eine kurze Beschreibung, reproduzierbare Schritte, mögliche Auswirkungen und – falls vorhanden – einen Fix-Vorschlag an. Niemals echte Passwörter, Neon-Verbindungsstrings, Session-Cookies oder personenbezogene Daten mitsenden.

Aktuell unterstützte Version ist ausschließlich der Stand auf `main`.
