# Security Policy

Do not disclose a security issue in a public issue first. Use [GitHub Private Vulnerability Reporting](https://github.com/unbindall-org/unbindall/security/advisories/new), or privately contact a maintainer through the address listed on the GitHub organization profile.

Include a short description, reproducible steps, potential impact, and a suggested fix if you have one. Never send real passwords, Neon connection strings, session cookies, or personal data.

Only the current state of `main` is supported. Released versions and notable security fixes are listed in [CHANGELOG.md](CHANGELOG.md).
